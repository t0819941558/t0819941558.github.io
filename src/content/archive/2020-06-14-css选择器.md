# [](#选择器 "选择器")选择器

1.后代元素选择器

```css
div p {}
```

2.直接子元素选择器

```css
div > span{}
```

3.属性选择器

```css
[title^="one"]{}
```

4.相邻兄弟选择器(后面元素)

```css
span+p{}
```

4.全部兄弟选择器(后面元素)

```css
span~p{}
```

5.交集选择器

```css
div.one {}
```

6.并集选择器

```css
div, .one{}
```
