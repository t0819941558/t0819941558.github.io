# [](#Emmet语法-用来快速创建html元素 "Emmet语法:用来快速创建html元素")Emmet语法:用来快速创建html元素

1.div>span (div内嵌套span)

2.div+span (div兄弟span)

3.div>p\*5 (div内嵌套5个p标签)

4.div>p+span^h1+strong

```html
<div>    <p></p>    <span></span></div><h1></h1><strong></strong>
```

5.div>(p>span)+h2来代替^

6.div#main>div.box+p.p1+span.title^div#footer>div.box2

```html
<div id="main">    <div class="box"></div>    <p class="p1"></p>    <span class="title"></span></div><div id="footer">    <div class="box2"></div></div>
```

6.生成内容用{}

7.#main

```html
<div id="main"></div>
```
