这里是 **深度思考**，由 t08 维护。

网站正在从旧版知识博客迁移为新的学习记录空间。之后的技术笔记、研究记录和阶段性思考都会以 Markdown 保存，并通过网页后台发布。

## 新站有什么

- 清晰、安静的中文阅读体验
- 可搜索的 Markdown 学习文档
- 自动生成的文章目录
- 一只会观察、打盹，也会回应你的 3D 小老虎

## 内容如何保存

每篇文章都直接保存在 GitHub 仓库中，因此可以追踪历史、比较修改，并随时迁移到其他工具。
