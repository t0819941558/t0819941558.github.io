2. 工具调用：说话 -> 真正做事  记忆：短期记忆（上下文） 长期记忆（用户画像）  循环： 纠错  Prompt

3. MCP 、A2A、Memory(claude.md、embdding、context)

4. Plan-and-Execute    react

5. Agent 当成一个销售的员工，workflow是 给他排班表，什么时间做什么事情  MCP是打电话工作所需的电话簿，skill是打电话所需的话术（如何完成这份工作） tools是话术的执行单元 function-call 是打电话这个动作
